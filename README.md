# 🔐 加密解密工具 / Encrypt-Decrypt Tool — V0.3.1

> 一个功能全面、界面精美的本地加密解密 Web 工具，支持多种文本编码方式、图片与 Base64 互转，以及音频与 Base64 互转。所有操作均在浏览器本地完成，无需服务器，保护隐私安全。  
> 版本 0.3.1 简化了视觉模式，统一为稳定高效的“正常版”，开箱即用，无需选择。

---

## ✨ 功能特性

### 文本加密 / 解密
- **Base64** 编码/解码  
- **URL** 编码/解码  
- **HTML 实体** 编码/解码  
- **十六进制 (Hex)** 与文本互转  
- **二进制** 与文本互转  

### 图片处理
- 图片 → Base64：将图片转换为 DataURL 格式的 Base64 字符串  
- Base64 → 图片：将 Base64 字符串还原为图片并支持下载  

### 音频处理
- 音频 → Base64：支持 MP3、WAV、OGG 等格式转 Base64  
- Base64 → 音频：将 Base64 还原为音频并支持在线播放、下载  

### 界面与体验
- 🌓 **深色/浅色主题** 一键切换（支持跟随系统）  
- 💡 输入/输出区域支持清空、一键复制  
- 📱 响应式设计，完美适配移动端  
- 🚀 纯本地运行，无服务器依赖，隐私安全

## 🚀 快速开始

### 方法一：使用 Python 启动本地服务器（推荐）
项目内置了快速启动脚本，会自动打开浏览器。

```bash
# 确保已安装 Python 3
# Windows 用户双击 `启动.bat` 即可
# 或在终端执行：
python 快速启动.py
```

### 方法二：直接打开 HTML 文件
由于浏览器安全限制（如跨域、剪贴板 API 限制），部分功能可能无法在 `file://` 协议下正常工作，建议通过本地服务器运行。

## 🎨 界面与性能（V0.3.1 更新）

从 V0.3.1 开始，**项目统一为“正常版”**，移除了以往“有特效版”与“无特效版”的选择。正常版保留了现代化的视觉设计（渐变、圆角、阴影等），同时去除了高耗能的动画和毛玻璃滤镜，兼顾美观与性能：

- 页面加载速度更快（~150-200ms）  
- 内存占用降低约 25%  
- 兼容所有现代浏览器，对老旧设备更友好  
- 无需首次弹窗选择，打开即用，体验更流畅  

如果您仍需要旧版的特效效果，可继续使用 V0.3 版本。
